# Protection lists (Spec 023)

The privacy protections ship three data files in `app/src/main/assets/protection/`.
They change **only** with an app release; the app never downloads them (Constitution §I).

| File | Source | Licence |
|---|---|---|
| `tracker_hosts.txt` | Generated by `build_tracker_hosts.py` from EasyPrivacy + EasyList | CC BY-SA 3.0 (derived, modified) |
| `public_suffix_list.dat` | https://publicsuffix.org/list/public_suffix_list.dat, unchanged | MPL-2.0 |
| `tracking_params.txt` | Hand-written | none (own work) |

## Refreshing `tracker_hosts.txt`

1. Download the Tranco top-1M list (https://tranco-list.eu/) and unzip `top-1m.csv`.
   It is used only to decide which EasyList ad-server hosts are kept; no Tranco data is written.
2. Run from the repository root:

   ```bash
   python3 -I tools/protection-lists/build_tracker_hosts.py --popularity /path/to/top-1m.csv
   ```

   The script downloads EasyPrivacy and EasyList, applies the rules in research R1, and fails if
   the gzip size exceeds 300 KB.
3. Commit the regenerated asset and note the host count and size in the PR.

Never run the script from Gradle or CI.

## Refreshing `public_suffix_list.dat`

Replace it with the upstream file, keeping its MPL header, and note the `VERSION`/`COMMIT` lines in the PR.
